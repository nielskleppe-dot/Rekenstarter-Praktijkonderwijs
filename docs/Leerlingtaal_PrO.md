# Leerlingtaal in Rekenstart

Gebruik gewone, volwassen taal voor PrO 3 en 4. De leerling moet aan rekenen kunnen denken en weten wat de vraag betekent.

- Schrijf korte zinnen. Geef één opdracht per zin.
- Gebruik een duidelijke vraag: hoeveel is nodig, hoeveel ligt er, hoeveel moet erbij?
- Begin een lesdoel met ‘Ik kan’. Noem één concrete rekenvaardigheid.
- Gebruik steeds hetzelfde woord voor hetzelfde voorwerp.
- Schrijf noodzakelijke rekenwoorden wel op. Leg ze kort uit met een bekend voorbeeld.
- Houd de beroepssituatie herkenbaar. Zorg, Groen, Techniek, HBR en Economie hebben hun eigen materialen en beelden.

| Vermijd | Schrijf bijvoorbeeld |
| --- | --- |
| Geregistreerde aantallen | De aantallen op de lijst |
| Tabelwaarden | Getallen in de tabel |
| De resterende ruimte | De ruimte die overblijft |
| Welke werkactie is nodig? | Wat moet je doen? |
| Welke aanvulling is vereist? | Hoeveel moet erbij? |
| Interval op de schaal | Stapje tussen twee streepjes |
| Formuleer een besluit | Vertel wat je moet doen |
| Bereken de benodigde hoeveelheid | Reken uit hoeveel je nodig hebt |

Leerlingen kunnen op de dia een korte uitleg openen bij onder andere omtrek, oppervlakte, tarra, gemiddelde, eenheid en voorraad. Toon alleen woorden die op die dia voorkomen, met hoogstens twee tegelijk.

De volledige bibliotheek gebruikt bewust geschreven lesdoelen. Ze worden niet meer automatisch omgebouwd uit een lange docentzin. `src/student-language.mjs` bewaart deze doelen en de afspraken voor terugkerende teksten. De werkkaartassistent krijgt dezelfde aanwijzingen voor leerlingteksten.
